# EaseUI

A modern React + TypeScript UI component library built with Vite and Tailwind CSS. EaseUI is designed to help developers build polished interfaces faster with reusable components, smooth animations, and a clean design system.

## Overview

This project combines:

- React for component-driven UI development
- TypeScript for type safety and maintainability
- Vite for rapid local development and production builds
- Tailwind CSS for modern styling utilities
- Reusable UI components such as buttons, cards, inputs, modals, navbars, and tooltips

It is structured as both a component showcase and a reusable library foundation.

## Features

- Reusable UI components
- Theme-ready styling system
- Animated input and hover effects
- Demo pages for each component
- Simple Vite-based development workflow

## Included Components

- Button

- Additional utility and animation helpers

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm or yarn

### Installation

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

Then open the local URL shown in the terminal, typically:

```bash
http://localhost:5173
```

## Available Scripts

```bash
npm run dev
```
Starts the Vite development server.

```bash
npm run build
```
Builds the project for production and generates the library bundle.

```bash
npm run preview
```
Serves the built app locally for preview.

## Notes

This project is currently set up as a library-style UI toolkit with a preview/demo application for testing component behavior and design consistency.
